You can download all the applications we provide on this page.

Compared to downloading from the software website, this page is more **convenient** for users who have **difficulties** in **choosing versions** and **installing applications**.
:::

::: details How to open the System Information window using shortcuts
Press `Win + R` keys, input `msinfo32` and press `Enter` key, then the System Information window will be opened. In the "System Type" section, you can see the type of your current system (such as 64-bit or 32-bit).
:::
