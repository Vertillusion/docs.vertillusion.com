# Pogget

> A lightweight file interaction efficiency tool that is completely free and supported by every user. To protect your information security, if you download it through the website, please make sure the download source is from the official website [https://pogget.vilinko.com](https://pogget.vilinko.com).
You are welcome to participate in improving the documentation [here](https://github.com/VilinkoStudio/docs.vilinko.com/edit/source/docs/pogget)!

## ✨ Learn more

* **📦 Mapping Storage Box**
No file transfers. Just establish connections. Drag commonly used files hidden in various parts of the computer into it, and they can be opened directly on the desktop. No extra space is occupied, and you can clear them anytime after use, making it light and hassle-free.
* **📦 Regular Storage Box**
The small drawer on the desk is prepared for daily work. Files will be moved into it, where you can rename, delete, or archive them. Put all the materials you need to handle today in here for peace of mind.
* **📦 Target Storage Box**
Similar to a regular storage box, but it directly binds the storage box with the existing folders on the hard drive. Whatever you drag and organize on the storage box, the real folders will change accordingly. No need to switch windows back and forth, with two-way synchronization, what you see is what you get.
* **🧲 Magnetic Access Window**
When the open/save dialog box is triggered, it immediately docks next to the window. The content of the access window is identical and interchangeable with the storage box. When you're unsure or need to temporarily store a file, you can create a hidden storage box as a temporary workspace for easy access.
* **⚡ Quick Panel**
The contents of all storage boxes will appear here. You can quickly press a shortcut key to trigger them when needed, eliminating the hassle of searching for files. Additionally, you can split the panel to manage files like a browser.

## ✨ How to Start
This project does not require complicated installation steps.
1. Extract the file (Pogget.exe) to any directory you like, or place it directly on the desktop. README.md is the project description and does not need to be placed.
2. Open the app directly.
If the system prompts that the dll is missing, you can download the patch from [https://aka.ms/vc14/vc_redist.x64.exe](https://aka.ms/vc14/vc_redist.x64.exe).

## 🗑️ How to Uninstall

This application adheres to the green application principle and will not write any bloated information to your system. The uninstallation process is very simple:
1. Delete all files (user basic data, optional) in Settings -> View User Data.
2. Right-click the small icon on the taskbar to exit the program.
3. **Simply delete the program files.**
