# Cache folder

::: danger
Deleting cached files may result in file loss. Data is priceless. Please operate with caution.
:::

Pogget's cache folder for Roaming is located in the following location.

```Bash
C:\Users\YourUsername\AppData\Roaming\Vilinko\Pogget
```

You can also press the WIN + R keys, type `%appdata%\Vilinko\Pogget` , and click OK to open it.
