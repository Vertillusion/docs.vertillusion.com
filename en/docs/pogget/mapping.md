# Mapped Storage and Regular Storage

::: Tip
The titles of mapped storage boxes and regular storage boxes differ in font weight.

Mapped storage boxes use light-weight titles, while regular storage boxes (including the target storage box) use bold and italic titles.

:::

Mapped storage is similar to a "mirror image" of a file, or in other words, a shortcut to the file added within the storage box.

Changes you make after opening the file will be applied to the file, but the "delete" operation will only delete the "shortcut," not the file itself.

![explorer_CigyCVECUz](https://github.com/user-attachments/assets/0a123f4e-b054-444d-b5d3-c562f652feee)

::: Tip
To prevent accidental deletion, the default option when deleting a component is "Disassemble and Return," which will put the file back in its original location. If the original location cannot be found, the file will be placed on the desktop.

:::

A physical storage box is a storage box in a physical sense, suitable for scenarios such as file organization. Files are moved into the storage box, and operations such as "delete" will actually remove the files from the computer.
