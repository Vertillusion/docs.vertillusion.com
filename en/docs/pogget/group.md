# Component Grouping

### Setting Colors
Components with labels of the same color can be grouped. After grouping, adjacent components of the same color will be **magnetically snapped together**. Adjusting the window position, window size, etc., will affect nearby grouped windows. Grouping windows allows for easy and flexible window layouts.

::: tip
If the color is set to white, it will be considered ungrouped.

:::

### Merging and Grouping
After grouping, components with the same label can be merged into one large component. The merged component's position is independent of its previous position.
