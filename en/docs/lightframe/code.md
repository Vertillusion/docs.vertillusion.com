# Custom Command List

<research>2</research>

1. (File) Open File
2. (*.vui) Open Card
3. (Text) Hover Tip (Component hover only)
4. `LightFrame.action:NewStickyNote` Create New Sticky Note
5. `LightFrame.Bin` Drag to Delete (Component only)
6. `LightFrame.dohover` Fade (Component only)
7. `LightFrame.emitter:Express` Particle (Diffusion)
8. `LightFrame.emitter:Love` Particle (MC: Heart)
9. `LightFrame.emitter:Bubbles` Particle (MC: Bubbles)
10. `LightFrame.emitter:Test` Test Emitter (Animation Playback)
11. `LightFrame.MC.BedUI` Bed (Old Version)
12. `LightFrame.MC.GameBedUI` Bed
13. `LightFrame.MC.ChestUI` Chest
14. `LightFrame.MC.CraftingTable` Crafting Table
15. `LightFrame.setwp:Path` Change Wallpaper
16. `LightFrame.panel:StickyNote` Sticky Note Creation Page
17. `LightFrame.panel:MCThemed Minecraft` Themed Component Creation Page
18. `LightFrame.OpenSpace` Focus Space
