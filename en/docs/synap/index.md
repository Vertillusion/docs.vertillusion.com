# Synap

> A minimalist software for quick thinking capture.

::: warning 
This application is still in the development stage, and the production version has not been distributed yet. If you encounter any issues while using the **invited test version**, please report them to the Github repository [Issues](https://github.com/VilinkoStudio/Synap/issues).
:::

## Introduction
Traditional note-taking software often requires users to plan in advance: "Which folder should this inspiration go into?" This forced categorization can create a psychological burden, causing fleeting inspirations to slip away during the tedious classification process.

Therefore, the capture of inspiration and its systematic organization should be completely separated. This software does not force users to build grand knowledge frameworks but instead provides a pure recording interface that faithfully captures the flow, divergence, and convergence of consciousness. The interface design is as simple and lightweight as a system memo, yet it possesses far superior thinking evolution capabilities, as well as powerful search and browsing functions, making it easy for users to find and organize later.
