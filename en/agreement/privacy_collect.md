# Public Disclosure of Personal Information Collection

This page publicly discloses the personal privacy information collection items and their actual usage scenarios across Vilinko Studio's current services. It is designed to help users transparently understand how we collect and utilize your privacy-related data.

::: tip Version
Last Updated: June 8, 2026
:::

::: warning
Your personal data remains 100% localized on your device and is never used for training, analysis, or telemetry. We do not collect any personal information unless you voluntarily choose to sign up for an account, in which case only your essential account credentials will be securely stored to manage your profile.
:::

## Pogget
| Permission / Data Type | Purpose of Collection & Description of Use Cases |
| :---: | :--- |
| **Storage & File Access** | **1. User-Initiated Authorization:** We only access files or data when you actively add them, solely to provide file selection, magnet link parsing, desktop organization, and content backup services. Your data is stored strictly on your local device and is not linked to any online services.<br>**2. Inter-project Interoperability Support:** To enable feature synergy across our product ecosystem, the application may access interoperability data generated by other Vilinko projects when necessary.<br>**3. Access Limitation Commitment:** Except for the aforementioned scenarios, this application will never access or read any other private files, photo albums, or third-party application data on your device. |
| **Runtime Status & Configuration Data** | To ensure the proper functioning of the application and deliver a personalized experience, the application reads and writes necessary local configurations and caches:<br>1. **Application Status Tracking:** Such as the first-launch flag, current version number, etc.;<br>2. **UI Configuration Data:** Such as interface layouts, user-defined settings, and UI states;<br>3. **Performance Optimization Data:** Such as temporary cache files, etc. |
| **Network Connection & Data Communication** | This application establishes network connections only in the following explicit scenarios and remains completely offline at all other times:<br>1. **Version Update Checks:** To fetch the latest version information;<br>2. **Essential Information Services:** To view official announcements, developer insights, and sponsor information;<br>3. **Data Analysis Assistance:** Operational data related to crashes and errors is collected to optimize product performance *only* after obtaining your explicit authorization. |
| **Browser Invocation** | Triggers external browsers to open links such as Afdian, allowing you to view developer information or provide sponsorship support. |

## Pogget Store

::: warning Notice on Permission Usage
Inspiration Station is an online web service. The following permissions are acquired via the relevant permissions you grant to your web browser. If you have not granted these permissions to your browser or Inspiration Station, we will prompt you for authorization when required by essential services. Once you explicitly deny authorization, the following permissions will not take effect.       
The Windows and Android applications of Inspiration Station downloaded from Vilinko-related websites are built and run based on Webview. Their permission management is identical to accessing the service directly via a web browser.
:::

| Permission / Data Type | Purpose of Collection & Description of Use Cases |
| :---: | :--- |
| **User Behavior & Engagement Data** | When you visit specific pages, download third-party components, undergo CAPTCHA/bot verification, vote, or search for specific content, your clicks, scrolls, page visits, and input behaviors are collected via the browser to prevent malicious bot access and specific cyber-attacks. |
| **Specific Identifiers** | When you access Inspiration Station, your IP address is retrieved through the browser to analyze traffic sources and defend against malicious attacks. When you use the download feature, your UserAgent information is obtained via the browser to identify the device system type and version, ensuring a more compatible browsing experience. |
| **Local Cache Access** | When you browse component descriptions or load dynamic content on Inspiration Station, the system requests cookies and localStorage permissions to prevent browser lagging caused by loading excessive dynamic content simultaneously. |
