::: details Vilinko Studio 对于爱发电平台 API 数据的使用声明
Vilinko Studio 通过爱发电平台 API 获取的数据仅限于以下必要范围：   
1. **基础交易数据**：订单号、支付时间、金额及商品标识符（仅用于服务开通与对账）
2. **用户身份标识**：爱发电平台分配的唯一用户ID（非个人信息，用于账号关联）

我们承诺：
- 仅通过加密通道获取上述数据，且存储期限不超过服务终止后**180日**（《个人信息保护法》第19条）。
- **不获取或存储用户在爱发电平台的敏感信息**（包括但不限于银行卡号、完整身份证号、生物特征）。
- 数据使用严格限定于**服务履行、争议解决及法定义务**三大场景（《网络数据安全管理条例》第12条）。 

责任限制声明：
- 因爱发电平台API接口故障、数据错误或政策变更导致的服务问题，我们不承担赔偿责任  
- 用户与爱发电平台之间的数据争议，由该平台直接负责处理（《电子商务法》第57条）  
- 本声明构成协议的有效组成部分，与协议其他条款具有同等法律效力
