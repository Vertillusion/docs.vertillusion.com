错误码说明 ​

本文档定义了系统中使用的错误码及其含义，便于开发人员快速定位和解决问题。

错误码格式 ​

所有错误码均为6位数字，按错误类型分组：

  • 100000-109999: 网络连接错误
  • 110000-119999: API错误
  • 120000-129999: 数据处理错误
  • 130000-139999: 系统错误

详细错误码列表 ​

网络连接错误 (100000-109999) ​

  • 100001: 请求超时，请检查网络连接

    • 含义：API请求超过了设定的时间限制
    • 可能原因：网络不稳定、服务器响应慢
    • 解决方案：检查网络连接，稍后重试

  • 100002: API请求被浏览器阻止，尝试使用代理重新请求

    • 含义：浏览器或浏览器扩展阻止了API请求
    • 可能原因：广告拦截器、安全扩展拦截
    • 解决方案：尝试禁用浏览器扩展或使用代理

  • 100003: 无法连接到API服务器，可能是网络问题或浏览器扩展拦截

    • 含义：Chrome浏览器下无法建立API连接
    • 可能原因：网络问题、浏览器扩展拦截
    • 解决方案：检查网络连接、暂时禁用浏览器扩展、尝试使用其他浏览器

  • 100004: 无法连接到API服务器，可能是网络问题或CORS限制

    • 含义：非Chrome浏览器下无法建立API连接
    • 可能原因：网络问题、CORS配置问题
    • 解决方案：确认API服务器已正确配置CORS、尝试使用代理服务器转发请求、检查浏览器安全策略

  • 100005: 无法连接到API服务器，可能是网络问题或CORS限制

    • 含义：通用网络连接错误
    • 可能原因：网络问题、服务器不可用
    • 解决方案：检查网络连接，确认服务器正常运行

API错误 (110000-119999) ​

  • 110001: API端点不存在，请检查API路径是否正确

    • 含义：请求的API路径不存在
    • 可能原因：API路径错误、服务器配置问题
    • 解决方案：检查API路径是否正确，确认服务器配置

  • 110002: HTTP错误

    • 含义：服务器返回非2xx状态码
    • 可能原因：服务器错误、权限问题
    • 解决方案：检查服务器状态，确认请求参数和权限

  • 110003: API错误

    • 含义：API返回了错误代码和消息
    • 可能原因：请求参数错误、业务逻辑错误
    • 解决方案：检查请求参数，参考API文档

系统错误 (130000-139999) ​

  • 130001: 未知错误
    • 含义：未分类的错误
    • 可能原因：系统bug、未预见的情况
    • 解决方案：查看控制台日志获取详细信息，联系开发人员

错误码使用方式 ​

在代码中，错误码与错误信息对应使用，便于定位问题。例如：

javascript
// 抛出错误码对应的错误
throw new Error(`[110001] API端点不存在，请检查API路径是否正确`)

如何贡献 ​

如果您发现新的错误类型需要添加错误码，请联系开发团队更新此文档。
