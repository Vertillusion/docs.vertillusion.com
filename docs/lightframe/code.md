# 自定义命令列表

<research>2</research>

1. (文件) 打开文件
2. (*.vui) 打开卡片
3. (文本) 悬停提示(仅限组件 悬停)
4. `LightFrame.action:NewStickyNote` 新建便签纸
5. `LightFrame.Bin` 拖拽删除(仅限组件)
6. `LightFrame.dohover` 淡化(仅限组件)
7. `LightFrame.emitter:Express` 粒子(扩散)
8. `LightFrame.emitter:Love` 粒子(MC:爱心)
9. `LightFrame.emitter:Bubbles` 粒子(MC:气泡)
10. `LightFrame.emitter:Test` 测试发生器(动画播放)
11. `LightFrame.MC.BedUI` 床(旧版)
12. `LightFrame.MC.GameBedUI` 床
13. `LightFrame.MC.ChestUI` 箱子
14. `LightFrame.MC.CraftingTable` 工作台
15. `LightFrame.setwp:路径` 切换壁纸
16. `LightFrame.panel:StickyNote` 便签纸创建页面
17. `LightFrame.panel:MCThemed Minecraft` 主题组件创建页面
18. `LightFrame.OpenSpace` 专注空间
