# 映射收纳和普通收纳

::: tip 提示 映射收纳盒和普通收纳盒的标题有粗细之分。映射收纳盒为细体标题，普通收纳盒(包括目标收纳盒)为粗体+斜体标题 :::

---

映射收纳类似于文件的"镜像"，或者说在收纳盒内添加了文件的快捷方式。
您打开文件后所做的修改会被应用到文件，但"删除"操作仅会删除这个"快捷方式"而非文件本身。
![explorer_CigyCVECUz](https://github.com/user-attachments/assets/0a123f4e-b054-444d-b5d3-c562f652feee)

---

::: tip 提示 为了防止误删，删除组件时默认选项为"解散并归位"，文件会被放回到原始的位置。如果无法找到原始位置，文件会被放置到桌面。 :::
物理收纳盒是物理意义上的收纳盒，适用于文件整理等情景。文件会被移动进入收纳盒中，"删除"等操作会真的将文件从电脑上移除。
