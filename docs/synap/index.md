## 产品介绍
传统笔记软件常要求用户在记录前预先规划：“这个灵感该归入哪个文件夹？”这种强制分类带来的心理负担，往往会让转瞬即逝的灵感在繁琐的归类流程中悄然流失。

因此，灵感的捕捉与系统化整理，应实现彻底的分离。本软件不强迫用户搭建宏大的知识架构，而是提供一个纯粹的记录界面，忠实捕捉意识的流动、发散与收敛。界面设计如系统备忘录般简洁轻盈，却具备远超其上的思维演进能力，以及强大的检索与浏览功能，便于用户后续的查找与整理。
