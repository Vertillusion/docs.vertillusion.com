# 关于 Vilinko Studio
> 价值与美不为任何方圆所束缚。

Vilinko 这个名字是一个合成的词组。  
是由 <u>Vi</u>sion（想象）,<u>Link</u>（连接）,和twin<u>kle</u>（如星星般灵感的闪烁）组成的。   
当无数的想象被创造出来，再回望，它定会如星河一般，发光发热。
